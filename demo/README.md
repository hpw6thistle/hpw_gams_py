# 系統帳號與權限申請平台

首頁可直接進入提出申請、我的申請、進度查詢及管理者入口。申請採四步：申請方式、人員資料、系統權限、確認送出。

桌面預設展開圖示與文字側欄，Logo 可回首頁；手動收合後仍保留功能名稱。手機使用附文字的選單按鈕。介面採暖白底與企業紅，步驟條置中，選項為幾何短卡；提供短暫切頁與收合動畫，尊重減少動態偏好。填寫頁不顯示申請摘要或步驟提示。

登入帳號統一採權限使用人的員工編號；不使用 Email 或手機當登入帳號。英文姓名為選填，最多 60 字；本人與代辦申請均可留白。上下步驟按鈕同寬，可返回修改並於最後確認送出。系統及角色依 v19 原檔分類，四個六字短名稱供介面辨識，不代表已查證的官方完整產品名。

操作說明見 [操作驗收表](./acceptance.html)。資料保存在目前瀏覽器，管理者入口仍是本機角色流程，不是真正的伺服器身分驗證；尚未連接寄信及正式資料庫。管理選單僅在進入管理角色後顯示。
